# Getting help

- **How do I…? / Is this a bug?** Ask in [Discussions → Q&A](https://github.com/Okohedeki/scroll-studio/discussions).
  Search first; include your `site.yaml` (or the part that matters), the command you ran, and the output of
  `studio doctor`.
- **A bug you can reproduce:** [open a bug report](https://github.com/Okohedeki/scroll-studio/issues/new/choose).
- **An idea for the engine:** start in [Discussions → Ideas](https://github.com/Okohedeki/scroll-studio/discussions);
  once it has a shape, it becomes an issue.
- **A security problem:** never in public. Follow [SECURITY.md](SECURITY.md).
- **Installing models, ComfyUI and Blender:** [docs/INSTALL.md](docs/INSTALL.md), then `studio doctor`.
- **Something you made:** share it in [Discussions → Show and tell](https://github.com/Okohedeki/scroll-studio/discussions).

Scroll Studio is maintained by volunteers. Questions are answered when someone has time; the response targets in
[docs/maintainers/triage.md](docs/maintainers/triage.md) apply to issues and pull requests.
