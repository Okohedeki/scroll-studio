A field of `site.yaml`, or one value of a field, can now be marked deprecated in `engine/spec.py` with `json_schema_extra=deprecated("2.0.0", "`replacement`")` (see "How to deprecate a field" in `docs/compatibility.md`). It keeps validating; `engine.spec.deprecations(spec)` lists each use with its place, replacement and removal version, `studio build` prints them as warnings, the `set_spec` MCP tool and the Studio spec save return them, and the generated reference marks the field. Nothing is deprecated yet.
