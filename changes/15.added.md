What the stylesheet hard-coded is now a theme token, each defaulting to today's value so existing sites look the same: `theme.space` (gutter, max width, caption width), `theme.type` (headline scale, running-text size), `theme.shade.strength`, `theme.motion` (easing, how blocks arrive, how smooth scrolling follows), `theme.grain` (film grain over the page) and `theme.phone`, one phone width for the stylesheet and the runtime alike.
