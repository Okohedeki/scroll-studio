`studio ads` makes placement-sized ads (1x1, 4x5, 9x16, 16x9, 1.91x1) from the picked product stills, with the product
kept whole and the headline and call to action set on a brand-coloured band; `studio listing` writes a title, bullets
and a description from a text backend, or a marked draft when none can run. Set them up with `outputs.ads` and
`outputs.listing` in `project.yaml`.

`studio video` makes a short product video from the picked stills: push-ins, cross dissolves, an end card with the
ads' copy, and a voiceover read by a speech backend (ElevenLabs, when `ELEVENLABS_API_KEY` is set), with optional
music; with no speech backend the video is silent. Set it up with `outputs.video` in `project.yaml`.

`studio layouts` writes several product page layouts from the stills, listing and ads copy, each arranged differently and checked against the site spec; `--pick` makes one the site. Set it up with `outputs.layouts`.
