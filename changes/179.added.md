`studio ads` makes placement-sized ads (1x1, 4x5, 9x16, 16x9, 1.91x1) from the picked product stills, with the product
kept whole and the headline and call to action set on a brand-coloured band; `studio listing` writes a title, bullets
and a description from a text backend, or a marked draft when none can run. Set them up with `outputs.ads` and
`outputs.listing` in `project.yaml`.
