A frozen moment can fly a named camera move instead of keys: `freeze: { image: ..., move: dolly-zoom }` (or `{move: orbit-left, amount: 0.8, at: [0.5, 0.6]}`) renders the same rig a generated beat's named move uses through the frozen frame's depth, offline and in seconds, so a dolly zoom, an orbit or a crane can move through a still picture of people without a video model redrawing them. The storyboard, the stand-in clips, `studio freeze --report` and `studio inspect` read the move as the beat's camera.
