A site.yaml is now treated as untrusted input: paths and ids that would leave the project folder, `javascript:` links and markup in text or theme values are refused or shown as plain text on the built page, and Markdown pages no longer pass raw HTML through. Existing projects that follow the documented forms build as before; section ids and page slugs must now be plain names (letters, digits, `-`, `_` and `.`), so rename any that contain spaces or slashes.
