Generated stills and the builders' image edits (`edit:` images, relighting, the layers plate, the product-in-scene blend,
the deep zoom's detail pass) now go through a model router: local models first, exactly as before, with provider
backends (Anthropic for text, OpenAI for images and edits, any OpenAI-style text server) used only when a spec's
`models:` asks for them and their key is set; a paid provider is never a silent fallback. `studio models` lists what can
run, and `studio build --profile` shows where a build's time goes.
