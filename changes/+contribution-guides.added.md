Contribution guides: CONTRIBUTING.md (ground rules, what a complete feature includes, consistency rules for themes and styles), a CLA, code of conduct, security policy, issue forms and a pull request template. CI runs the tests on every pull request, `main` takes changes only through pull requests with the tests green, and `tests/test_conformance.py` checks every theme preset and style (tokens, contrast, block types, docs, and a page with every block type in every style).
