Local generation spends less time loading models. Releasing ComfyUI's GPU memory between jobs no longer drops its
cache of loaded weights, so the next job on the same model moves it back from system RAM in seconds instead of reading
it from disk again, and product stills paint every scene before any blending pass, so the image and edit models each
load once. `studio build --profile` now lists ComfyUI's time per model, with how many jobs had to load their model.
