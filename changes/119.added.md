Scroll Studio is easy to try without a GPU. `studio doctor` opens with what this machine can build without one (photo parallax, kinetic type, artwork, vector art, maps, data, code, live 3D, miniature worlds, scans, every block and all 32 styles) and what needs ComfyUI or Blender, each ticked or with the one install that makes it ready. `studio new my-site --laptop` writes a starter whose scenes need no models (kinetic type, or your own photo as a photo parallax with `--image photo.jpg`), a few blocks and a style, and builds with no ComfyUI, Blender or FFmpeg. A new [Try it on a laptop](docs/laptop.md) page goes from `pip install` to a built site, and the README opens on the live showcase beside it. Photo parallax without PyTorch now says what to install instead of failing on an import.
